# Sudoku

A minimalist Sudoku application, organized as a [Turborepo](https://turborepo.dev) monorepo managed with [pnpm](https://pnpm.io).

## Requirements

- Node.js 24 or later
- pnpm 11 (`corepack enable`)

## Getting started

```sh
pnpm install
```

## Repository layout

| Path                         | Purpose                           |
| ---------------------------- | --------------------------------- |
| `packages/eslint-config`     | Shared ESLint configuration       |
| `packages/typescript-config` | Shared TypeScript base `tsconfig` |
